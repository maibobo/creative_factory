# FPGA设计验证流程

系统需求分解由工程师完成：明确功能边界、主要指标和关键参数的初步定值，作为设计输入。

人工系统需求分解 → 设计规格与方案 → 代码编写与审查 → 测试点、用例与验证方案 → 验证代码、仿真与每日回归 → implement及时序收敛。

四个Skill阶段末分别等待人工确认。已确认的阶段不重复询问；实质变更返回对应阶段确认。implement及时序收敛属于第四阶段，提前评估资源和时序为可选项。

| 阶段 | 流程入口 | 主要输出 |
|---|---|---|
| 1 | [方案文档设计](skills/fpga-design-spec/SKILL.md) | 设计方案Word、设计规格Excel |
| 2 | [代码编写与审查](skills/fpga-rtl-development-review/SKILL.md) | RTL、编译/人工检视/综合检查结果 |
| 3 | [测试点、用例与验证方案](skills/fpga-verification-planning/SKILL.md) | 测试点及用例Excel、验证方案Word |
| 4 | [验证代码、仿真与回归](skills/fpga-simulation-regression/SKILL.md) | 验证代码、每日回归脚本、测试结果、仿真报告及实现/时序结果 |
