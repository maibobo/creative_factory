# 测试点、用例与验证方案

从各模块功能规格及上下文分解测试点，主要按基本功能分类，按实际场景补充多模块接口交互、总线、跨时钟和异常。AXI结合实际配置考虑burst、len、outstanding数量、超时、qos等。

采用项目/IP关联编号，如DDR.001.001，反标规格编号及描述，关联用例名称。用例反标测试点编号及内容；准备与输入聚焦本例核心变量和激励思路，写相关信号的中文含义、来源、选用原因及关联功能，通常约3–30行。按表行顺序安排执行。

同步写验证目的、UT/IT等方法、环境组件、架构与数据流、组件功能设计、代表用例实例；checker、激励、RM等分别说明。非标准SV/UVM按真实组成组织章节，验证规模和回归安排随功能复杂度确定。

保留设计规格页，输出测试点/用例Excel和验证方案，等待本阶段人工确认后再生成验证代码。
