# 阶段输入 / 输出矩阵

| 阶段 | 主要输入 | 主要输出 | 进入条件 | 退出条件 | 主要 Skill |
|---|---|---|---|---|---|
| G0 入项/环境 | 需求、工程、器件、工具信息 | 项目清单、环境基线、依赖清单 | 项目范围明确 | 关键环境可发现或已阻塞 | `vivado-revision-control`（可选） |
| G1 设计方案 | 原始需求、协议、寄存器、IP 手册 | 设计方案、接口表、时钟复位图、性能和异常定义 | 需求输入齐全 | 设计基线获确认 | `fpga-design-solution` |
| G2 RTL 实现 | 设计基线、RTL 规范、IP/XCI/XDC | RTL、IP 配置清单、变更记录、开放问题 | G1 PASS | RTL 可解析且偏差已记录 | `fpga-rtl-verilog-development`、`vivado-ip-configurator` |
| G3 静态验证 | RTL Candidate、工程、约束 | Compile/Elab、Lint、CDC/RDC、DRC 报告 | G2 输出完整 | Critical/Major 已关闭或接受 | `vivado-rtl-elaboration-analysis`、`vivado-rtl-lint` |
| G4 独立 Review | 设计基线、RTL、G3 报告 | Review 报告、整改清单、Stable RTL | G3 可审查 | Review Gate PASS | `fpga-rtl-verilog-code-review` |
| G5 验证方案 | 设计基线、Stable RTL、Review 风险 | P0/P1/P2 计划、Test ID、Expected、Coverage/回归准则 | G4 有效 | 全部设计/风险可追溯 | `fpga-simulation-verification-plan` |
| G6 TB 实现 | 验证方案、Stable RTL、IP 模型、Golden Data | TB、Checker、参考模型、Seed、TB 说明 | G5 PASS | 测试项已实现或阻塞有记录 | `fpga-verilog-tb-development` |
| G7 仿真执行 | TB、Stable RTL、仿真工程、运行契约 | 日志、波形、Coverage、回归结果、诊断报告 | G6 可运行 | 结果有证据且问题已分类 | `vivado-simulate-rtl` |
| G8 综合/实现/时序 | RTL、XDC、IP、仿真结果 | 综合/实现/Timing/Methodology/DRC 报告 | G7 满足准入 | 时序和方法学满足门限 | `vivado-timing-methodology-checks` |
| G9 硬件调试 | bitstream/PDI、板卡、ILA/VIO 配置 | 采集波形、硬件问题记录、复现步骤 | G8 产物可下载 | 关键硬件场景验证完成 | `hw-ila-debug`、`hw-vio-debug` |
| G10 发布交付 | 全部基线、报告、脚本、证据 | 发布包、重建脚本、版本说明、风险清单 | G8/G9 按项目要求完成 | 独立环境重建通过 | `vivado-revision-control` |

## 阶段间关键数据流

```text
设计方案
  ├──> RTL 实现
  ├──> Review 基线
  └──> 验证计划

RTL Stable
  ├──> TB 实现
  ├──> 仿真执行
  └──> 综合/实现/时序

Review 风险 ──> P1 Test ID
仿真失败   ──> RTL/TB/设计/环境问题闭环
时序失败   ──> RTL/约束/架构问题闭环
```
