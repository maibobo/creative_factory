# 海思风格数字 IC 代码规范包实施计划

## 总体方案

在 `E:\centOS\代码规则建立\代码规范输出` 建立可维护规范包，形成两套彼此独立的规范：

- ASIC RTL：仅使用可综合 Verilog-2001。
- 验证环境：SystemVerilog + UVM，不作为 RTL 编码依据。
- 综合本地三份资料，但排除文件头规范和一般性注释格式；仅保留用户要求的“语义段注释”。
- 自定义规则使用结构化配置作为唯一数据源，后续修改配置即可同步更新规范正文和检查表。
- 全程不使用 `unslop`。

## 交付内容与关键规则

- 输出主文档：
  - `01_ASIC_Verilog_RTL代码规范.md`
  - `02_SystemVerilog_UVM验证代码规范.md`
  - `03_用户自定义规则.md`
  - `04_代码评审检查表.md`
  - `05_来源与冲突裁决.md`
  - `README.md`
- ASIC RTL 规范：
  - 采用 M1、M2、R 三级规则，并为每条规则分配稳定编号。
  - 默认一个 `always` 块只允许一个赋值目标；同一向量的不同位段视为一个目标。
  - 只有复位、使能和主要分支结构完全或大部分相同，或状态机按 `state` 集中描述更清晰时，才允许多目标；必须添加语义段注释说明原因。
  - 禁止 `wire a = expr;`；统一写成 `wire a; assign a = expr;`。由 `always @(*)` 驱动的变量必须声明为 `reg`。
  - 简单单表达式组合逻辑允许 `assign`；有条件分支或 `case` 时使用 `always @(*)`，禁止难以阅读的嵌套三目运算。
  - 时序逻辑只使用非阻塞赋值，组合逻辑只使用阻塞赋值；所有分支使用 `begin/end`。
  - 默认低有效异步复位、同步释放；复位同步器属于批准单元，不允许业务 RTL 自行实现。
  - 单比特 CDC 使用批准的两级或多级同步器；多比特 CDC 使用握手、Gray 编码或异步 FIFO，禁止逐位打两拍。
  - FIFO、同步器、DMUX、ICG、存储器宏和算术 IP 必须从批准单元注册表例化；Vivado XPM 只允许位于 FPGA 原型适配层，不进入 ASIC 签核 RTL。
  - 保留海思风格的小写信号、`_n`、`_ff1/_ff2`、`U_<MODULE>` 等命名方式，但取消旧规范中的固定 20/32 字符和 72 列硬限制。
  - 注释按功能、时序、协议或状态转换等语义段组织，解释设计意图和约束，不逐行复述代码。
- SystemVerilog/UVM 验证规范：
  - 独立规定 package、interface、class、factory、config、phase、objection、sequence、driver、monitor、scoreboard、SVA、coverage、TLM、并发和日志规则。
  - 当前可执行基线固定为 VCS Q-2020.03-SP2-7 + UVM 1.2。
  - 同时提供到 [IEEE 1800-2023](https://standards.ieee.org/ieee/1800/7743/) 和 [IEEE 1800.2-2020](https://standards.ieee.org/ieee/62530-2/11429/1800.2/7567/) 的兼容映射。
  - UVM 方法学引用 [Accellera UVM 1.2 User Guide](https://www.accellera.org/images/downloads/standards/uvm/uvm_users_guide_1.2.pdf)；现代参考实现信息引用 [Accellera UVM](https://www.accellera.org/downloads/standards/uvm) 和 [官方 UVM Core](https://github.com/accellera-official/uvm-core)。
  - 禁止隐藏的 `default_sequence`、`uvm_do*`、无边界通配 `config_db`、组件内随意管理 objection、分析端口中执行阻塞重任务，以及用 driver 数据代替 monitor 数据采集覆盖率。
- 可维护接口：
  - `config/custom_rules.json` 保存四条用户规则、严重级别、适用范围、例外条件、正反例及检查提示。
  - `config/approved_cells.json` 提供同步器、FIFO、DMUX、ICG、RAM 和算术 IP 登记模板；实际模块名和路径保持待填，不虚构标准单元。
  - `tools/sync_custom_rules.py` 提供 `--check` 和 `--write`：前者检查文档是否与配置一致，后者更新规范和检查表中的受控区块。

## 示例与验证

- 提供纯 Verilog RTL 模板，覆盖单目标 `always`、组合逻辑、复位、CDC 单元例化和状态机例外写法。
- 提供完整最小 UVM 工程：interface、transaction、sequence、sequencer、driver、monitor、agent、scoreboard、env、test、SVA、DUT、顶层及 `filelist.f`。

  - JSON 可解析，规则编号唯一且引用完整。
  - 自定义规则同步脚本执行 `--check` 无差异。
  - 文档链接、生成标记和目录结构完整。
  - RTL 示例不含 SystemVerilog RTL 语法、声明赋值 wire 或多驱动。
  - UVM 示例使用 VCS 2020/UVM 1.2 编译运行，完成正常事务、复位、计分板清空、断言和最终 PASS/FAIL 检查。
  - 若远程 VCS 环境不可用，记录具体阻塞和未执行项，不把静态检查冒充编译通过。
