## 统一用户接口

数据与串行接口使用主动高控制和降序总线：

- TX：`tx_data[63:0]`、`tx_rem[2:0]`、`tx_sof`、`tx_eof`、`tx_valid`、`tx_ready`
- RX：`rx_data[63:0]`、`rx_rem[2:0]`、`rx_sof`、`rx_eof`、`rx_valid`
- 复位输入：`reset`复位Aurora协议/通道；`gt_reset`连接10G `PMA_INIT`，执行GT/PMA完整复位
- 状态输出：`user_clk_out`、`system_reset_out`、`channel_up`、`rx_crc_error`

`system_reset_out`直接来自核的 `sys_reset_out`，供 `user_clk_out` 域用户逻辑复位。`rx_crc_error`仅在 `crc_valid_i && !crc_pass_fail_n_i` 时拉高。

公共接口不再导出 `lane_up`、`hard_err`、`soft_err`、`crc_valid` 和 `crc_pass_fail_n`。这些状态仍存在于Aurora内部及官方verification中；业务逻辑只使用 `channel_up` 判断链路可用。

`tx_rem/rx_rem`只在EOF拍有效，值为有效字节数减1；0到7表示1到8个有效字节。TX源必须保持一拍，直到 `tx_valid && tx_ready`。RX没有ready输入，下游必须在 `user_clk_out` 域连续接收，需要停顿时由集成工程添加FIFO。

## 用户时钟

本配置的并行接口宽度为64 bit，所以：

```text
USER_CLK = 10.3125 GHz / 64 = 161.1328125 MHz
```

156.25 MHz是 `10.3125 GHz / 66` 得到的64B/66B块速率，不是64-bit用户接口时钟。Gearbox通过周期性TX backpressure把长期接受比例调整为64/66。
