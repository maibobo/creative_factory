## 统一用户接口

- TX：`tx_data[31:0]`、`tx_rem[1:0]`、`tx_sof`、`tx_eof`、`tx_valid`、`tx_ready`
- RX：`rx_data[31:0]`、`rx_rem[1:0]`、`rx_sof`、`rx_eof`、`rx_valid`
- 复位输入：`reset`和 `gt_reset`，二者职责不同且不合并
- 状态输出：`user_clk_out`、`system_reset_out`、`channel_up`、`rx_crc_error`

`loopback`和 `power_down`不再作为公共输入，内部固定为 `3'b000` 和 `1'b0`。公共接口同时删除 `lane_up`、`hard_err`、`soft_err`、`frame_err`、原始CRC两线以及所有GT启动调试状态。官方verification仍保留并检查这些IP原生诊断信号。

`rx_crc_error`定义为 `crc_valid_i && !crc_pass_fail_n_i`。`rem`只在EOF拍有效，值为有效字节数减1；0到3表示1到4个有效字节。RX没有ready输入，下游必须连续接收，需要停顿时由集成工程添加FIFO。

## 为什么USER_CLK是31.25 MHz

每个用户时钟传送32 bit，即4个8-bit数据字符。8B/10B编码把每个8-bit字符编码为10个串行位，所以一拍对应40个线上位：

```text
USER_CLK = 1.25 GHz / (4 bytes x 10 encoded bits/byte)
         = 1.25 GHz / 40
         = 31.25 MHz

有效用户数据率 = 32 bit x 31.25 MHz = 1.0 Gb/s
```

125 MHz是GT参考时钟，不是用户接口时钟。
