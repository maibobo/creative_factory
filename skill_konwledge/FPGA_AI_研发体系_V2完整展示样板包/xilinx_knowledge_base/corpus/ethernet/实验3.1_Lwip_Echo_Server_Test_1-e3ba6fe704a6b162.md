Lightweight IP (lwIP) is an open

LwIP是Light Weight (轻型)IP协议，有无
操作系统的支持都可以运行。LwIP实现
的重点是在保持TCP协议主要功能的基
础上减少对RAM 的占用，它只需十几
KB的RAM和40K左右的ROM就可以运
行，这使LwIP协议栈适合在低端的
嵌入式系统中使用。
