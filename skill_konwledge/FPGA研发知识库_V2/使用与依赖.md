# 使用与依赖

## 按功能读取

1. 工程师提供已分解并初步定值的系统需求；后续阶段使用已经确认的规格、方案及测试表。
2. Agent读取对应Skill、阶段知识入口，按当前模块功能选择主题。搜索词可组合功能、接口、故障现象，例如“DDR AW W 独立握手”“FIFO FWFT reset busy”。
3. 主题正文用于技术判断；涉及精确端口、时序、IP参数或工具选项时，回查该页链接的来源。先核对来源版本与本项目是否匹配。
4. 按模板输出，保留反标关系。阶段末由工程师确认。问题修复改变已确认功能或判据时，更新相关规格、用例和设计。

可用Agent已有文件搜索或编辑器全文搜索。例如在本包根目录用 `rg -n "FWFT|reset.busy" knowledge sources`。没有rg时直接按目录读取Markdown，不需要安装检索后端。

## 内外网使用

内网已有本地Agent时，将完整目录复制过去即可按相对链接阅读。GLM5.2使用同一套Skill正文；若Agent不自动识别Skill目录，直接指定读取相应SKILL.md。`agents/openai.yaml` 是可选界面元数据，不是流程依赖。模型上下文长度与文件读取上限由实际Agent配置决定，首轮只读本阶段与本功能相关材料。

外网可在本地资料不足时查匹配版本的官方资料，记录标题、版本、章节、检索日期及适用范围，再将所需正文或技术摘录存入本包。不能只留下内网无法访问的URL。联网不会自动改变项目已确认的参数和规范。

来源中原始E/F/R盘路径和网页地址是历史定位信息，基本使用依赖的是随包副本。历史日志、原始IP模型及商业EDA未全部打包；缺少这些材料时，相应验证保留待执行状态。

## 运行依赖

| 用途 | 所需条件 | 本版交付 |
|---|---|---|
| 阅读和文本搜索 | UTF-8文件读取；可选rg/编辑器搜索 | Skill、知识正文、来源文字、示例均本地保存 |
| 编辑Word/Excel | Office类软件，或本地Python与python-docx/openpyxl | 模板可直接编辑；自动生成依赖由目标环境准备 |
| 每日回归调度 | Python 3.6+标准库、项目编译/仿真入口 | 复用V1脚本及空配置模板；由项目填写并接入每日调度 |
| SV/UVM示例 | 对应仿真器、许可证、UVM库 | 示例源码、filelist及原VCS命令；本轮未执行 |
| 综合、implement、时序 | 项目认可的Vivado、器件/IP、XDC/Tcl及许可证 | 技术说明与检查内容，不含EDA安装包或许可证 |

本机已指定Vivado入口为 `D:\Xilinx_2020_2\Vivado\2020.2\bin\vivado.bat`；远程环境记录为 `C:\Xilinx\Vivado`。这是部署记录，实际迁移需确认可执行文件、版本及许可证，不能把本机路径直接写死在新项目脚本中。

DOCX生成后检查OOXML结构、表格、字段与样式，不渲染PDF/PNG。Office自动化所需库可在移植时另备与目标Python版本匹配的离线安装包。本轮没有安装、下载或搬运依赖。

## 维护

交付件或知识条目需要上传/发布时，按[安全检查说明](references/上传与发布安全检查.md)处理发布副本；先脱敏，按需要选择文档或代码包加密。安全检查不增加第五个开发阶段。

技术内容按主题维护，四个阶段链接到同一份内容。规则变更保留规则编号，核对正文、配置快照、检查表及示例；来源索引记录新版本。项目修复经验写清现象、适用配置、根因、检查方法和结果范围，再由工程师确认是否纳入共享知识。

包内自检可在根目录运行 `python tools/check_package.py`，使用Python 3.10+标准库，检查相对链接、Skill入口、来源副本哈希、Office结构与Excel字段/字体。仅在原始资料仍可访问且需要检查其完整性时增加 `--verify-sources`。此工具不执行EDA，不联网，不改写文件。
