# 内容缺口与使用边界

| 缺口 | 对当前使用的影响 | 补齐材料 |
|---|---|---|
| 已排除的厂商PDF不能作依据 | 不宣称本包全部要求来自核实的厂商制度 | 用户后续认可的有效规范、术语与评审实例；当前沿用已确认项目规范 |
| 目标项目参数和设计规格 | 历史示例值不能直接作为新需求 | 工程师完成需求分解与初值，并确认方案 |
| 批准公共模块/IP清单仍是历史快照 | 不能据pending条目生成真实批准实例 | 当前项目可复用模块、接口、版本、配置和工程师确认 |
| 官方文字副本存在历史版本 | 不能推定与当前Vivado/IP完全一致 | 目标工具版本的产品指南、XCI、模型及示例；核对差异后更新摘录 |
| Aurora/DDR/PCIe完整IP模型和目标板配置未随包提供 | 本包可指导用户侧设计与验证，不能直接完成PHY/板级验证 | 项目IP模型、器件/内存/板级参数、约束与运行环境 |
| 以太网策略来自未完整验证的历史设计 | 只能复用审查关注点和有范围的实现说明 | 当前协议/IP依据、系统顶层及实际仿真结果 |
| 历史案例部分只有过程性记录 | 历史转述不等于当前实测通过 | 需要复现时取得对应源码快照、原始日志和工具配置 |
| 内网Agent、Python/Office依赖与GLM5.2实际能力 | 文件可移植不等于已经验证模型执行效果 | 内网环境检查和同任务试点，按实际结果补依赖 |

资料版本或配置不匹配时，指出受影响的功能及缺少什么依据；已有明确部分继续完成。不得通过补造企业规则、IP参数或PASS结果填平缺口。
