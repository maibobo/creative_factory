# DDR与MIG

适用于DDR用户侧读写、BIST及MIG集成。先确认器件/内存、用户接口、位宽、时钟、地址窗口、burst与outstanding能力；内存物理位宽与AXI位宽分别记录。

## 初始化与事务

历史MIG工程在ui_clk域使用ui_clk_sync_rst和init_calib_complete控制业务启动。当前设计需按所用IP复位协议核对业务释放条件，不能直接把板级参考时钟作为用户接口时钟。

AXI写地址与写数据独立握手；B响应与R响应检查响应码，读数据检查有效拍、最后拍及期望内容。完成状态明确是“发完”“已响应”还是“读回校验结束”。计数、首错信息与错误保持按规格设计。

## 测试分解

| 功能类别 | 适用场景 |
|---|---|
| 初始化 | 未校准时不启动、校准与复位条件满足后启动、恢复后首次事务 |
| 基本读写 | 已确认地址区域与数据模式、首末地址、单拍或支持的burst |
| 总线交互 | AW/W不同接受次序、读写反压、响应延迟、多事务上限 |
| 异常 | 错误response、读回数据错误、超时、运行中复位及恢复 |
| 扩展压力 | 多区域、地址/长度边界、连续或并发访问；限于规格支持范围 |

准备与输入应写清例如“init_calib_complete（校准完成）由MIG行为模型控制，延迟拉高以检查启动门槛”，并反标该功能点；不用列出所有DDR引脚。

## 复用边界

历史最小BIST采用单拍、单outstanding、32KiB区域和固定模式，是教学/最小工程范围，不是本知识库对DDR能力的限制。行为AXI内存模型通过只支持用户逻辑功能结论，校准/PHY/真实DDR器件时序需要对应模型或板级验证。
