# 以太网

适用于已有RGMII接收、帧过滤、分类缓存及DMA方向的经验。先区分物理接口采样、帧解析、过滤策略、缓存路由和软件可见结果；已有风暴过滤项目尚非完整验证通过的成品IP。

## 设计与实现关注

明确前导码/SFD、数据与FCS的范围、VLAN处理、长度单位、CRC算法及表示方式。过滤开关究竟旁路哪些策略要逐项定义，不能从名字推断完全放行。

输入不能被后级随意暂停时，缓存与丢弃策略需一致。数据和描述符同步提交或排空；按帧统计接收、过滤、路由丢弃与DMA完成，避免多个阶段计数混用。固定优先仲裁还需说明低优先流量是否允许饥饿。

配置阈值、MAC表和窗口跨域时说明整体更新和生效时刻。窗口边界与新帧到达同拍、清统计与新事件同拍是适用的功能边界。

## 测试与历史限制

按规格选择帧长度、VLAN、CRC、MAC/ACL、窗口计数、重复检测、拥塞、背靠背、分类和DMA场景。每种异常的预期丢弃原因与优先级取当前设计，不能自动继承历史编码。

历史工程有“CRC残余32'h2144_DF1C”“10ms窗口”“长度60–1514Byte”等取值，还含特定前导码判定和VLAN剥离行为；它们是该实现审计结果，不作为所有以太网接口的通用标准。本包不以这些值定义新项目规格。

已有资料提示描述符异常后的排空、命令超时、配置CDC和系统顶层/IP依赖仍有缺口。测试点表存在不能作为仿真通过证据。
