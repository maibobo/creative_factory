# 跨IP集成

适用于Aurora/PCIe/DDR/以太网之间的桥接、DMA和数据路由。

| 集成边界 | 需要核对的技术内容 | 验证观察点 |
|---|---|---|
| 用户接口转换 | 方向、握手、位宽、字节序、尾字节与帧界限 | 输入/输出握手、有效字节、帧数及顺序 |
| 时钟域 | 源/目的时钟与复位、CDC信息类型、启动依赖 | 跨域事件次数、首个事务、复位恢复 |
| 缓冲与反压 | 不可停入口、最长暂停、数据/描述符容量、丢弃 | 满空、阈值、在途数据、丢弃后下一帧 |
| 地址与DMA | 字节/拍单位、对齐、窗口、环深度、发布顺序 | 地址、长度、响应、commit前后指针 |
| 状态与IRQ | sticky、清除、新事件、请求确认与软件可见层级 | 中断状态、清除后重触发、残留事务 |

沿实际数据路径逐段取证，最后做端到端比较。中间层完成不能替代后级数据正确；出现不一致时先定位第一个错误边界，避免直接修改最终报错模块。

对输入无反压、输出可暂停的桥接，定义缓存耗尽时是丢整帧、报错还是依赖上游流量约束。复位发生在下游已接受半帧之后时，已接受的数据不能由本模块“撤回”；当前系统需明确接收端复位、abort或截断处理语义。

接口名字有历史兼容性时增加清楚的中间信号和说明，核对实际模块方向与赋值。历史案例中的valid/ready交叉只适用于该旧命名，不能固化成通用接线规则。
