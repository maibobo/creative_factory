# 代码阶段知识入口

以已确认的规格和方案为输入，先读[规则适用说明](../规范/规则适用说明.md)，再根据功能读取技术主题。规则编号用于描述具体问题，ASIC专属内容按适用范围处理。

| 代码涉及内容 | 技术入口 |
|---|---|
| 命名、always、状态机、位宽与可综合性 | [RTL结构与审查](../通用/RTL结构与审查.md)、[RTL规则正文](../../sources/rules/01_ASIC_Verilog_RTL代码规范.md) |
| 总线或接口交互 | [AXI与流接口](../通用/AXI与流接口.md)、[架构与接口](../通用/架构与接口.md) |
| 异步交互、复位和FIFO | [CDC](../通用/时钟复位与CDC.md)、[FIFO](../通用/FIFO与数据一致性.md) |
| IP调用和wrapper | [IP目录](../知识目录.md)、[典型问题](../案例/典型问题与修正.md) |

四步检查分别记录：语法编译的真实输出；Skill辅助及人工lint/CDC检视；工程师对功能、时序、接口与异常的检视；综合对不可综合代码、结构推断、非预期结构和关键告警的检查。未做工具检查时不写工具PASS，未人工检视时保留待检视。

[检查表](../../sources/rules/04_代码评审检查表.md)作为项目适用项的核对材料，不能直接把原ASIC签核表全选为必做。最终implement及时序收敛留在第四阶段。
