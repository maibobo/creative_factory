# 验证策划阶段知识入口

按已确认功能规格和模块上下文展开。先读[测试分解与验证方法](../验证/测试分解与验证方法.md)，并按功能选择下表材料。

| 功能上下文 | 补充测试场景的知识 |
|---|---|
| 总线、事务及流数据 | [AXI与流接口](../通用/AXI与流接口.md)：独立通道、反压、burst、ID、响应和超时 |
| 跨时钟、缓存、帧边界 | [CDC](../通用/时钟复位与CDC.md)、[FIFO](../通用/FIFO与数据一致性.md)：异步事件、复位、满空、数据与描述符一致性 |
| DDR初始化、Aurora链路、PCIe DMA、以太网过滤 | [IP主题](../知识目录.md)、[跨IP集成](../IP/跨IP集成.md)：正常、边界、异常与模型能力 |
| UT/IT环境、RM与checker组织 | [SV环境与检查组件](../验证/SV环境与检查组件.md)、[典型问题](../案例/典型问题与修正.md) |

同步输出测试点、用例和验证方案。测试点主要按基本功能分类，关联用例名称并反标规格编号与描述；用例反标测试点编号与内容。准备与输入只说明本例关键变量、信号中文含义、来源及刺激原因，通常约3–30行。表中行顺序就是回归顺序。

验证方案说明目的、UT/IT等方法、环境组件、架构与数据流、各组件功能以及代表用例实例。完成条件按本项目功能和边界确定。
