# 验证实施阶段知识入口

使用已确认测试点、用例及验证方案，依据功能选择基本TB、轻量SV、完整SV或已有UVM环境。

| 当前任务 | 读取内容 |
|---|---|
| 编写激励、monitor、RM、checker、scoreboard与覆盖 | [SV环境与检查组件](../验证/SV环境与检查组件.md)、[验证代码规范](../../sources/rules/02_SystemVerilog_UVM验证代码规范.md) |
| 编译、展开、仿真、用例入口和每日回归 | [仿真回归与定位](../验证/仿真回归与定位.md)、[回归脚本说明](../../references/每日回归脚本使用.md) |
| 分析协议/跨域/初始化失败 | [主题目录](../知识目录.md)、[典型问题与修正](../案例/典型问题与修正.md) |
| 功能验证基本完成后的implement及时序收敛 | [综合实现与时序](../工具/综合实现与时序.md) |

验证代码注释反标测试点，建立用例名称到实际入口的映射。按用例表顺序执行，功能失败保留输入、Seed、日志后继续，编译或环境异常停止。修复后复测并执行必要回归；实现或时序修改影响逻辑时也补做回归。

结果回填测试表；报告按测试版本、仿真与回归结果概览、分功能/用例的现象与结论、验证结论组织，记录未覆盖内容和遗留问题。验收不把行为模型通过扩展为真实IP或板级通过。
