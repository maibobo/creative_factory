# 代码编写与审查

依据已确认的功能规格与方案编写RTL，沿用现有规范及适用范围：单always默认单目标、wire声明与驱动分离、公共功能复用、语义段注释；例外按原规范。

分四步：语法编译检查；lint和CDC检查；人工检视功能；综合检查。语法检查使用项目编译入口。lint和CDC暂由Skill辅助检视及人工检查完成，不冒充工具检查结果。人工检视围绕功能点核对逻辑、时序、状态转换、接口交互和异常处理，人工结论由负责人填写。

综合检查不可综合代码、非预期结构、结构推断和关键告警；必要时提前评估资源与时序。整改后复查相关功能，实质改变已确认规格或方案时返回设计阶段确认。

提交RTL及审查结果，等待本阶段人工确认。implement及时序收敛在第四阶段完成。

按当前功能与配置，从[阶段知识入口](../../knowledge/stages/02_代码编写与审查.md)读取相关主题，必要时回查随包来源与示例。
