# 方案文档设计

依据人工完成需求分解并给出初定值的系统需求，按顶层、子模块整理规格，各模块按功能分类逐条写要求，同步生成Excel。

方案由功能要求展开，包含模块架构、信号列表、时序图和功能实现。详细设计中，各模块首小节列本模块规格及要实现的功能，可结合实现展开；后续说明具体设计。信号列表写信号名、中文名称、方向、位宽、含义，必要的时钟域和有效条件并入含义。概要设计可集中介绍规格，详细设计不另设整章规格说明。

按功能上下文选用知识库模板；关键初值或功能语义缺失时向工程师确认。已有确认有效时直接复用，实质变更重新确认。

输出设计方案和设计规格Excel，等待本阶段人工确认，不自动进入下一阶段。

按当前功能与配置，从[阶段知识入口](../../knowledge/stages/01_设计规格与方案.md)读取相关主题，必要时回查随包来源与示例。
