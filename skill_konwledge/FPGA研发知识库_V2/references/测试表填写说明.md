# 测试表填写说明

[三页签模板](../templates/设计规格_测试点_测试用例模板.xlsx)

| 页签 | 字段 |
|---|---|
| 设计规格 | 编号、模块、功能类别、功能名称、设计要求、备注 |
| 测试点 | 编号、类别、子类别、测试点内容、对应验证用例名称、设计规格反标 |
| 测试用例 | 编号、名称、验证层级、测试点反标、准备与输入、预期结果、执行结果 |

规格按顶层、子模块及功能类别逐条写；实际定值写入设计要求，备注补充说明。设计阶段填规格页，验证阶段沿用其编号与内容并补另外两页。

测试点编号为“项目/IP简称．三位类别序号．三位类别内序号”，如DDR.001.001；子类别单列。类别以实际基本功能为主，按上下文补充接口交互、总线、跨时钟及异常等。

规格反标写“编号＋具体描述”；用例的测试点反标写“编号＋测试点内容”。测试点关联用例名称，不只列用例编号。

准备与输入通常约3–30行，仅写本例核心变量与激励思路，说明中文含义、来源、为什么这样激励及所覆盖测试点。公共初始化在验证方案说明，本列写本例差异与必要触发关系；预期结果写可检查的现象、值或时序。

不设执行过程、优先级列，按行序运行。执行结果填实际结论及必要日志/Seed位置，未运行保持待执行。

三个页签微软雅黑，正文12pt、表头13pt，自动换行、顶部对齐；填写后按内容调整列宽、行高。
