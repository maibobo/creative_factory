# 模板使用

| 模板 | 结构 |
|---|---|
| [设计方案](设计方案模板.docx) | 概述、模块架构、分模块详细设计；模块内写功能规格、信号、时序、实现 |
| [规格与测试表](设计规格_测试点_测试用例模板.xlsx) | 设计规格、测试点、测试用例三个页签 |
| [验证方案](验证方案模板.docx) | 目的、方法、组件、架构与数据流、组件设计、用例实例 |
| [仿真报告](仿真报告模板.docx) | 测试版本、结果概览、分功能/用例结果、验证结论 |

设计规格：编号、模块、功能类别、功能名称、设计要求、备注。

测试点：编号、类别、子类别、测试点内容、对应验证用例名称、设计规格反标。

测试用例：编号、名称、验证层级、测试点反标、准备与输入、预期结果、执行结果。

测试点编号采用项目/功能前缀、类别序号和类别内序号，如DDR.001.001。规格和测试点反标都包含编号与具体内容。准备与输入通常3–30行，说明本例核心信号的中文含义、产生组件及激励理由。

Excel表头13pt、正文12pt、微软雅黑，自动换行并调整行高。按用例行顺序执行，执行结果由运行填写。Word保持封面、审批、修订和目录样式，章节按实际模块与环境展开。
