# RTDS 板内联动实测记录

日期：2026-10-19。当前 RX_VIO_TEST_ENABLE=1。结论：单主机基础应用数据通路与队列协议通过；不等同于全部RTL、真实Aurora或完整业务验收。

## 1. 实测范围

本机经远程Windows中转1轮，以及远程Windows直接连接ARM 2轮，六入口全部通过，共18个用例。远程首轮终端输出未显示，但完整板端/Windows结果均已回收核实PASS；第二轮显式回收输出并再次通过。每轮有独立编号，没有重试同一个VIO请求或同一个ACK。

| 用例 | 本机中转 | 远程直接第1轮 | 远程直接第2轮 | 实际判据 |
|---|---|---|---|---|
| env/regs | PASS | PASS | PASS | 版本2001、DDR3、起步/结束队列0、丢字0 |
| config | PASS | PASS | PASS | 两组配置回读，最后恢复8000/8000，不启动下行 |
| ddr | PASS+ILA | PASS | PASS | H2C/C2H各16Byte，00…0F逐字节一致 |
| single | PASS+ILA | PASS | PASS | 1块8Byte，通知读清不改队头，比较后一次归还 |
| multi | PASS | PASS | PASS | 2/8/2共12块、覆盖8槽、序号连续、数据一致 |

上行每块C2H请求/完成16Byte，比较前8Byte有效数据1100000022000000。三轮共39个上行块均比较并归还；硬件序号延续，不在每个实验重置。两种入口最终功能寄存器一致（温度允许变化）；逐块地址随环形游标变化，不要求不同轮的首地址相同。

## 2. 真实波形证据

仅第一轮保存三份波形并显示在已有Vivado中；两次远程复核不新增波形标签。

- ILA1 H2C：1次AW、2个64bit W、1次B，WSTRB=FF、末拍WLAST=1、BRESP=0。
- ILA1 C2H：1次AR、2个64bit R、末拍RLAST=1，两拍RRESP=0。
- 两个方向数据均为0706050403020100、0F0E0D0C0B0A0908；两份全部采样的ila_errors均0。
- ILA2：写地址100000，wsize=1个64bit拍，wdata=0000002200000011；writer状态0→1→2→3→0。source_valid保持4拍不代表接受4个数据。

四幅基于真实CSV/JSON的图和逐拍说明见 RTDS_ILA_VIO实测波形判读附册_20261019.docx。没有伪造GUI截图；没有渲染DOCX。

## 3. 异常和修正

首次ILA布防因CONTROL.TRIGGER_MODE只读停止，DMA尚未提交，原失败记录gui_validation_20261019_085920_1674d0.json保留。Tcl修正为先读设置，已匹配则不写；不匹配时写并回读，不忽略错误。旧版已经备份。控制传输改用SSH，避免R:共享盘I/O错误，不另开Vivado会话。

最终快照PROGRAM.FILE被配置存储器流程设为Vivado的spi_xcku040_pullnone.bit辅助文件；这只是主机属性，不证明器件已下载它，本轮未执行program_hw_devices。实际主设计调试核和数据闭环可用。未来Program Device前需重新选择已核对的TOP_main_spi4_50.bit。bit/LTX SHA256与原基线保持一致。
