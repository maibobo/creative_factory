已有ARM root终端：先Ctrl+C停止原watch，再运行：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_regs_watch.py
```

程序只读13个重点寄存器，不读取读清0x10，不写寄存器，不提交DMA。默认首屏显示基线，随后只追加业务寄存器变化与新的测试写入/归还日志，不清屏、不重复空闲内容；温度噪声默认不触发输出。可用--mode periodic --interval 5改为每5秒完整快照。RW列表示硬件访问属性，最近R/W仅是测试程序日志，不是对所有手动io操作的总线捕获。

现有Vivado接入与正式测试流程继续用 docs/RTDS_现有GUI接入与完整硬件验证计划_20261016.md。pc/verify_gui.py经本机中转；pc/launch_windows_check.py通过已验证Windows SSH连接启动远程直接复核。两者都要求当前GUI bridge已经source/start，只启动一个实验控制器；没有指定--jobs时按当天桥接目录发现，多个时须明确选择。
