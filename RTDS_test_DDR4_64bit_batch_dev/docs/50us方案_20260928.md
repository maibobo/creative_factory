## 二、关键词

- **RTDS 评估系统 / 四大板块**：后台显示、管理版（3588）、辅助版（FPGA）、主处理板（子机 IPG）
- **一体机框图对齐**：主机 + 子机（主从机）架构，一块 CPU 板 + 一块辅助板，"基础的东西搞错了"
- **PCIe**：Gen2.0（任务书要求、当前在调）／Gen3.0（设计余量，未调好）；两个物理上独立的 PCIe 设备
- **Aurora 10G / 1G 接口**：Aurora 传 50μs 数据流，1G 接口传 2μs 模拟数据流
- **50μs 交互周期**（任务书指标）／**2μs（实际 2.016μs）节拍**：31.25MHz 时钟、每 63 个周期同步一次
- **PCIe 中断抖动 60~70μs**：Linux 下无法满足 50μs 响应，讨论用"定时器中断主动扫描缓冲"破解
- **缓冲方案**：乒乓模式 → 8 块缓冲（约 700 毫秒软件抖动余量）／100ms 缓存块 / count 标记判更新
- **同步机制**：同步线"跑不掉"，主机通过 Aurora 发同步报文同步 N 个子机，全链条同一节拍
- **3588 侧工作**：通讯模块（读辅助板数据、拆包发后台）+ PCIe/中断驱动（李晨）
- **10 月三周计划**：第一周软件搞定 → 第二周联调 → 第三周校缺，10 月底具备条件（含十一假期）
- **需求单与阶段交付**：第一/二/三阶段划分、每周工作目标条目化、会议纪要
- **其他**：界面改造（王哲）、波形仿真（买国）、裸合/共享 RAM（老陈）、专利与任务书指标对齐
