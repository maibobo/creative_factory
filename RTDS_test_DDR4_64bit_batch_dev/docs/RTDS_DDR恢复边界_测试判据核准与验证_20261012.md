# RTDS_DDR恢复边界_测试判据核准与验证_20261012

## 1. 核查结论

2026-10-12，按用户“先不要改RTL”的要求，只修改regression/recovery_phase2_20261011/tb_backend_edge_recovery.sv及验证运行/打包脚本。未修改DDR4_SIM_RAM模型、生产DDR分支、MIG配置、时钟复位结构、寄存器或XDC。28个设计及工程文件修改前后SHA-256完全一致。原用例保留，没有删除用例，也没有允许OKAY与SLVERR任选其一。

本轮7个相关测试台×3个种子=21次通过，额外前一拍/后一拍边界各3次=6次通过，合计27/27。backend_edge_recovery的3种故障位置×3种子=9/9通过；其中同拍3次已计入21次，不重复计数。另有3次用于生成每个故障位置的匹配WDB/VCD，记录运行均通过，但不计入27次功能回归。原12:45回归的57/60和3次失败保留为历史结果；本轮没有把全部60次重新执行。

原失败根因是测试把“DDR复位请求已拉低”直接当作“模型storage_ready已在该采样沿之前失效”。SIM_RAM的sim_ready_pipe在上升沿以非阻塞赋值清零，该沿后端仍可看到旧ready=1，并在接受第二R时装入第三R成功响应。第三R随后已经展示，必须保持成功数据；第四R尚未展示，需返回零数据SLVERR。旧判据要求第三R也为SLVERR，错误起点提前了一拍。

| 模式 | 故障位置 | 第二R接受前ready | 第三R明确预期 | 第四R明确预期 |
| --- | --- | --- | --- | --- |
| EDGE_PHASE=-1 | DDR复位提前一个采样周期生效 | 0 | ID=1、原顺序第三拍、DATA=0、RESP=2、LAST=0 | ID=1、DATA=0、RESP=2、LAST=1 |
| EDGE_PHASE=0 | 复位请求与第二R接受位于同一采样周期 | 1 | ID=1、DATA=words[2]、RESP=0、LAST=0 | ID=1、DATA=0、RESP=2、LAST=1 |
| EDGE_PHASE=1 | 第二R接受后一个采样周期才撤销ready | 1 | ID=1、DATA=words[2]、RESP=0、LAST=0 | ID=1、DATA=0、RESP=2、LAST=1 |

这个关闭结论适用于当前RTL＋DDR4_SIM_RAM的已测边界，不能扩展为真实MIG、真实Root Port、门级时序仿真或板级全部通过。没有软件单独DDR复位寄存器；本测试直接驱动后端公开DDR复位端口，属于模块异常恢复边界，不是当前软件寄存器命令。

## 3. 设计检查与波形过程

R输出是一拍保持寄存器。RVALID=1而RREADY=0表示当前响应已经展示但尚未接受，此时DATA、ID、RESP、LAST必须稳定。恢复逻辑的recovery_read_left统计“还未装入保持寄存器”的拍数，不是“上游还未接受”的拍数，因此不能用该计数混淆已展示第三拍与剩余第四拍。

| 信号 | 准确含义 | 本场景的阅读重点 |
| --- | --- | --- |
| B.ddr_rst_n | 测试台施加的DDR复位请求，低有效 | 请求下降不等于SIM_RAM的ready已在该沿之前下降 |
| B.U_DDR.storage_ready | 模型/MIG及存储接口当前可用 | 决定新装入的响应是否走正常或错误路径 |
| B.ready | 业务允许接新事务的DDR状态 | 恢复校准完成但旧abort未清时仍为0 |
| B.rvalid/rready/rdata/rid/rresp/rlast | 业务侧当前已展示R及接受条件 | RESP=0为OKAY、2为SLVERR；只在握手沿数拍 |
| recovery_rload | 内部装入真实/错误R的事件 | 帮助解释同沿接受旧拍并装入下一拍；不用于反推测试预期 |
| recovery_read_fault/recovery_read_abort | 当前存储不可用或旧读已经失效的记录 | 失效后未展示剩余拍补零并SLVERR，不能改写已展示响应 |
| recovery_read_pending/recovery_read_left | 旧AR尚未收尾/还未装入的读拍数 | 最后R被接受后才能结束事务 |
| mem_wvalid/recovery_write_left | 实际进入存储的W/原突发尚未接受的W数 | 故障后原W继续接受并丢弃，不重放到恢复后的DDR |
| B.bvalid/bready/bid/bresp | 旧写及新写完成响应 | 旧写SLVERR、新写OKAY各一次，反压时字段不变 |
