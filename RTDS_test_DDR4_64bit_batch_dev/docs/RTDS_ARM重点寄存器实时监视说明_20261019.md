# ARM 重点寄存器实时监视说明

日期：2026-10-19。程序为 arm/rtds_regs_watch.py，Python 3.8 标准库。它是用户态只读观察工具，不是内核驱动，不提交 DMA，不修改 FPGA。

## 1. 在现有 root 窗口启动

先按 Ctrl+C 停止原先的 watch，再执行：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_regs_watch.py
```

默认后台每0.5秒采样，首次显示13项基线，之后只有业务寄存器变化才追加旧值→新值；不清屏、不重复打印相同状态。新的测试写入/读清/归还日志也仅追加一次，普通相同状态快照不重复打印。按Ctrl+C退出，无需新开前台窗口。没有新输出表示状态未变，后台仍在采样。当前队列已排空，因此0x30显示0属正常。

温度原始码0x0C仍参与读取和首屏显示，但默认不触发变化记录，避免温度噪声刷屏；需要关注温度时加--include-temperature。

只输出一屏、便于保存记录：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_regs_watch.py --once --plain
```

每5秒追加一屏完整快照（可选）：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_regs_watch.py --mode periodic --interval 5
```

默认变化记录模式下，降低后台采样频率：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_regs_watch.py --interval 1
```

## 2. 重点寄存器

实际物理地址=从PCIe资源表检测到的BAR0+偏移；当前BAR0为0xf0200000。例如0x30的实际地址是0xf0200030，不再叠加内部AXI地址。

| 偏移 | 属性 | 名称 | 重点含义 |
|---|---|---|---|
| 0x00 | R | VERSION | 当前身份应为0x2001；不匹配立即停止监视 |
| 0x04 | R | BUILD_ID | 当前0x20260914，构建标识，不是ARM当前日期 |
| 0x08 | R | BLOCK_CAPACITY | 单槽容量0x40000 Byte，不能当当前块有效长度 |
| 0x0C | R | TEMP_RAW | 温度原始码，不能直接当摄氏度 |
| 0x18 | R | RX_HEAD_ADDR | 待取队头DDR字节地址，逐块以硬件返回值为准 |
| 0x1C | R | RX_VALID_BYTES | 队头有效字节数，当前VIO块为8，空队列为0 |
| 0x20 | R/W1P | DOWN_TRIGGER_BUSY | 读忙状态，写1发起下行业务；本监视器不写 |
| 0x24 | RW | DOWN_START_ADDR | 下行配置地址，当前恢复为0x8000 |
| 0x28 | RW | DOWN_BYTES | 下行配置长度，当前恢复为0x8000，即32768Byte；本轮未启动该下行业务 |
| 0x2C | R | DDR_STATUS | 当前0x3：就绪；错误掩码0x1C应为0 |
| 0x30 | R | RX_BLOCKS | 已完成未归还块数0～8，与VIO1的rx_test_blocks_r对应 |
| 0x34 | R | RX_HEAD_SEQ | 队头序号；不是总接收数，空队列可回0 |
| 0x38 | R | RX_DROPPED | 丢字计数，本轮为0；不自动清历史 |
| 0x10 | RC，未轮询 | 通知读清 | 读取会清通知，纯观察不读取 |
| 0x14 | R/W1P，未轮询 | 上行块归还 | 写1归还一个块，只由完成数据比对的实验流程执行 |

R=只读；RW=可读可写配置；R/W1P=读状态、写1触发动作；RC=读后清除。上述是硬件访问属性，监视器对所有行均只读，不提供自动写入或自动归还。

## 3. 最近 R/W 显示区

程序只读 live_status.log 中测试程序已经记录的事件：

- R SNAPSHOT：实验读取的一组寄存器摘要。
- R CLEAR：实验明确执行过的一次通知读清；不是监视器自行读清。
- W INTENT：软件准备写入，不能单凭它认定硬件完成。
- W RETURNED：io调用已返回，仍需核对后续状态。
- ACK CHECK：块归还后已观察到队列数量减一。

它不是硬件总线抓包器，无法捕获任意终端里手动执行的io写操作。手动修改0x24/0x28后，新寄存器值可能在下一次采样显示出来；短暂脉冲、两次刷新间发生的变化可能漏过。当前ILA1也不采集BAR AXI-Lite事务，精确验证仍结合实验日志与数据比较。

## 4. 与实验同时使用

监视器不打开XDMA DMA节点，不拿实验独占锁，可以与单个正式实验并行只读观察。每帧13次io读取按顺序执行，不是同一时钟拍的原子快照；快速队列变化时地址、长度、块数可能来自不同瞬间，不能用这一帧代替正式程序的队头稳定检查。

纯观察时不要另行读取0x10、写0x14、写0x20或并行运行另一份实验。需要验证RW配置，应让正式config用例执行两组合法写入和恢复，观察工具只看结果：

```sh
python3 /root/rtds_joint_lab_20261016/arm/rtds_lab.py config --exclusive
```

命令在实验控制通道执行；已有root终端可保持监视。它只测试0x24/0x28，最后恢复，不写0x20启动下行。
