## 1. 默认观察：不用 Trigger

打开两组 VIO，点“+”添加全部信号，Refresh Inputs：

| 面板 | 看什么 | 操作 |
|---|---|---|
| `u_pcie/G_RX_VIO.U_VIO_RX_START` | busy=0，status[1:0]=3，status[2]=0；首次blocks=0 | `rx_test_start=0` |
| `u_pcie/U_PCIE_LINK_DEBUG/vio` | live[0:5]逐位正常、bit6=0、bit7=1；健康空闲常见00BF | `clear_vio=0`，`capture_axi_vio=0` |
| 新VIO计数 | uptime/seq更新、age不持续增长；掉链/PLL计数无新增 | 先保存，不清历史 |

LED17灭与live bit3=1交叉确认。live bit2=1只代表PCIe时钟活动。

## 2. 寄存器检查

```text
读0x00=0x2001；0x04=0x20260914；0x08=0x40000
读0x2C：低两位=3；保存0x2C、0x38
等0x20=0，写0x24=0x8000、0x28=0x10，分别读回
```

先不读 `0x10`，它会清通知/相关错误。上述地址是用户 BAR 相对偏移；不要再加内部 `0x40000000`。本阶段不用 ILA 触发，现有 ILA 不直接观察用户 BAR。

## 3. 16Byte DDR闭环

```text
数据：00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F
H2C写卡端0x8000，16Byte，等完成
C2H从同地址读16Byte，等完成和缓存同步
比较全部16Byte；保存0x2C/0x38
```

旧 VIO start 保持0，不写0x20=1。想看波形时，分别在H2C/C2H之前给PCIe原生ILA布防写/读握手；FDMA ILA不一定有活动。

## 4. 一个8Byte上行块：严格按序

| 顺序 | 动作 |
|---|---|
| 1 | 软件读0x30=0并准备轮询；旧VIO start提交0，确认busy=0、无fault |
| 2 | FDMA ILA设fdma_wareq==1，点 **▶ Run Trigger**，确认等待 |
| 3 | 旧VIO start提交1，**不用▶▶**；约100～200ms加事务时间后看块 |
| 4 | 预期accepted=2、busy=0、fault=0；0x30=1、0x1C=8；记录0x18返回地址 |
| 5 | 保存0x2C/0x38后读一次0x10；确认块仍在、队头不变 |
| 6 | C2H读取返回地址的8Byte并等完成；比对 `11 00 00 00 22 00 00 00` |
| 7 | 数据正确且DMA完成后，写 **0x14=1一次**；不需要写0 |
| 8 | 无新注入时0x30/0x18/0x1C回0；无新错误/丢字 |
| 9 | 下轮busy=0后再提交start=0→1；采波形则先重新▶布防 |

只有寄存器能力时可先观察块状态，但未读完数据不得盲写归还，数据比对项目记待测。多块按每块重新读地址/长度→C2H完成→一次确认，直到0x30为空。

## 5. 有对端再测下行和I/O

16Byte H2C完成 → 写0x24/0x28并回读 → 确认10G对端就绪 → FDMA ILA以fdma_rareq==1点▶ → 软件写0x20=1一次 → 记录忙回0 → 对端核对完整16Byte。仅忙回0不证明发送成功。

AM11/TEST3的cpu_sync_50us应为50µs周期、高低各25µs；用示波器测。当前VIO模式替换真实Aurora上行，start=0不能恢复正式接收。1G/真实接收等扩展步骤见完整手册。

## 6. 辅助命令与失败取证

已连接主工程Hardware Manager后可加载：

```tcl
source C:/project/RTDS/DDR/RTDS_test_DDR4_64bit_batch_dev/debug/joint_debug_20261015/pcie_joint_debug.tcl
::rtds_joint::snapshot
```

需要上行抓取时，用 `::rtds_joint::arm fdma_up` 代替手动设条件和点▶；它不会操作VIO。采集完成后 `::rtds_joint::save fdma`。下行对应 `arm fdma_down`；DMA对应 `arm dma_write`、`arm dma_read`；当前状态用 `now native`、`now phy`。

失败时先停新业务，保存寄存器/VIO/ILA/DMA日志；不先清历史、不先重启、不继续归还。助手脚本已离线检查，首次现场使用核对实际核路径与采集结果。
