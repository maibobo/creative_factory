# RTDS 恢复修复：第一阶段与测试计划（2026-10-11）

当前状态：代码已修改，待验证。本阶段未运行综合、elaborate、仿真；未开发或改写测试台。静态语法解析不构成功能通过。

## 代码与设计

- adapter：旧读排空、禁止旧响应进入TX/Byte1、用户域停止确认返回后再开放任务。恢复期间提交拒绝，0x20清零只代表命令结束。
- DDR后端：每方向一笔在途，保存ID与长度；DDR中断后读补SLVERR、写收完W后给错误B；已展示R/B保持。
- 真实MIG：转换器两侧和MIG AXI共用复位条件，每侧16拍释放，并同步确认。恢复记录不随存储侧复位清空。
- 接口未新增；CONV_DMA、INFO_EXCH、BD/XPR不需要本阶段生成新输出。已有DCP/旧波形对应修改前代码。
- 校准与业务ready可暂时不同；0x10只清诊断。单纯超时仍是诊断；DDR复位前数据保留、已发往对端的部分帧不在本修复可保证范围。

## 原用例重跑与阶段安排

1. 第二阶段先重跑TC-F11，覆盖三种中断。成功路径禁止H.reset；将成功日志改为RECOVERY_NO_RESET_CHECK，失败清理复位继续独立标记。测试失败须返回非零退出码。
2. 开发TC-F13～TC-F15，分别对后端读、后端写、跨任务隔离检查。所有模型故障在外部接口施加，不强制DUT状态。
3. 现有10项回归及TC-F09/F10/F12/M09均按当前活动源码重跑；TC-F09/1G及M08等须先核对活动实现与目标差异，不沿用归档通过。M09仍用250MHz、25000000生产参数，缩时结果不能替代。
4. TC-F16使用真实共享总线/IP环境；完整TOP CDC另做设计检查。真实Root Port、真实MIG、板级结果分别记录，环境不足保持未执行。
5. 后续新证据另存日期目录，记录源码SHA256、参数、工具、日志与波形。当前evidence保存2026-10-10失败事实。

## 新增用例

### TC-F13 DDR读事务中断与响应保持

关联测试点：P-48、P-50、P-51

层级：模块＋行为模型集成；优先级：P0；状态：未执行｜2026-10-11｜第一阶段仅修改代码与规划；待第二阶段验证

准备：真实rtds_ddr4_backend；DDR4_SIM_RAM；250MHz；ID取0、1及5bit最大值31；ARLEN取0/1/255，地址0x8000/0x8FF0按合法突发拆分。驱动器记录实际AR/R握手；DDR失效由ddr_sys_rst_n施加，不强制DUT内部状态。

执行：
1. 覆盖AR尚未接受、AR刚接受、首R前、中间R后、末R等待接受时撤DDR就绪。
2. 对RREADY=0的已展示响应保存五个字段，保持8/64/400拍，再释放。
3. 在剩余错误响应尚未结束时恢复DDR，尝试第二笔AR并检查未接受；原事务最后R被接受后再提交不同地址/ID的新模式。
4. 增加同拍DDR失效与R握手、DDR反复失效、读写并行；逐笔参考队列核对ID、数量和LAST。

判据：未接受AR无R；已接受AR恰有ARLEN+1次R握手。已展示拍在反压时不变；剩余替代拍DATA=0、RESP=2、ID为原ARID，仅末拍LAST=1；旧事务结束前无新AR握手，新事务数据逐拍匹配。0x2C响应错误/超时按实际事件置位；无全局复位恢复。

### TC-F14 DDR写事务中断与错误提交边界

关联测试点：P-49、P-50、P-51

层级：模块＋行为模型集成；优先级：P0；状态：未执行｜2026-10-11｜第一阶段仅修改代码与规划；待第二阶段验证

准备：真实后端、CONV_DMA及RTDS_RX_BLOCK_WRITER；后端专项AWLEN=0/1/255、ID=0/1/31；系统路径分别送2个32bit字和奇数尾字，保存ready_blocks、head_len、dropped_words基线。

执行：
1. 分别在AW前、AW后首W前、中间W后、全部W接受但B未产生、BVALID=1且BREADY=0时中断。
2. W先于AW到达并保持有效；恢复过程中送完原突发剩余W，观察存储侧无补写。
3. BREADY保持低8/64/400拍，恢复DDR仍保持低，再释放；重复中断并并行读。
4. 在系统路径检查错误写不计有效长度，随后送新模式并形成可读块；另覆盖一笔已展示OKAY B在失效期间保持。

判据：每笔已接受AW恰收AWLEN+1拍W并给一次B，B不早于最后W；中断且尚无已展示B时RESP=2、BID原值，剩余W不进入RAM/MIG。已展示B稳定，不能事后把OKAY改成错误。错误双字计丢2字、尾字计丢1字，长度不增；后续新写正常提交，无重复done。

### TC-F15 短断链与迟到事件跨任务隔离

关联测试点：P-47

层级：行为模型集成；优先级：P0；状态：未执行｜2026-10-11｜第一阶段仅修改代码与规划；待第二阶段验证

准备：沿用TC-F11真实INFO_EXCH/adapter/CONV_DMA/后端；fdma_clk=250MHz；用户时钟覆盖156.25MHz及较慢异步时钟，改变初相位。旧批0x8000、Byte1=1，新批0x9000/32Byte、Byte1=2，各用不同确定性数据。

执行：
1. 分别在请求待busy、R首拍/末拍、TX首拍/末拍、完成toggle回传期间撤PCIe/channel/lane就绪。短断链以同步域确实观察到失效为前提。
2. 中断后持续施加R反压，再释放；记录清理期间cfg_byte_valid、fdma_rareq和TX输出。
3. 恢复期间故意提交命令，检查拒绝且不创建任务；等待tx_recovering清零再提交新批。
4. 暂停用户时钟后恢复，重复断链100次；每次独立计数，不使用全局复位清理成功路径。

判据：0x20结束旧命令后旧R仍可排空；清理期间无新读请求、无旧Byte1事件。读busy=0、用户域停止确认、连续8个FDMA拍无旧done后才放行；用户时钟停顿时不提前放行。新批4个64bit拍、2帧、2次Byte1事件、1次完成，数据/地址/边界正确，无迟到完成截断新批。

### TC-F16 真实共享AXI路径与MIG恢复

关联测试点：P-51

层级：真实IP集成／板级；优先级：P0；状态：未执行｜2026-10-11｜第一阶段仅修改代码与规划；待第二阶段验证

准备：第二阶段使用当前F盘XPR与真实design_1、AXI Interconnect、Clock Converter、XDMA及MIG仿真支持环境；CPU与FDMA同时访问。没有可运行的真实Root Port/MIG环境时维持未执行，行为模型结果不能替代。

执行：
1. 正常并发读写，覆盖CPU长突发、FDMA每帧2拍读和每笔1拍写，记录修改前后延迟及吞吐。
2. 在仲裁等待、转换器两侧均有在途事务时复位DDR；按主机ID核对R/B完整返回和无串ID。
3. 检查两侧复位至少各保持16个本域时钟、MIG AXI同范围复位、新访问等待两侧释放确认；此项同时做设计检查。
4. 复位后重新写入已知数据再读，核对新任务；另运行真实PCIe链路重建及CPU软件错误处理。

判据：每个已接受AR/AW只完成一次、拍数与ID正确；无旧返回进入新事务、无互锁。bit1可先恢复，bit0待接口及错误收尾完成再恢复。真实IP必须给独立日志和版本，板级另记日期；DDR复位前数据不假定保留，吞吐实测数值单列，不预填通过。
