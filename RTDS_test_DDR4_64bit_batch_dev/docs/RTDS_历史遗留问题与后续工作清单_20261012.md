## H01 1G 四拍格式及同源节拍与活动源码不一致

优先级 / 当前状态：P1 / 当前失败，待统一活动版本

影响：四拍 16 Byte、Byte6=0xF0、统一 2 us 源事件与 50 us GPIO 的设计目标无法据当前活动源码判定通过。

关闭条件：活动 XPR 只指向确定版本；四拍字节与同源周期集成检查通过，真实 TOP 端口和管脚约束一致。

## H13 Aurora CRC、错误帧与子机端到端接收

优先级 / 当前状态：P1 / 待设计与板级验证

核查发现：历史 Aurora IP 配置启用 CRC32，但业务 wrapper 没有完整体现 CRC 有效/通过状态的使用策略；下游子机的控制脉冲、包字段与失帧处理也未由主机行为模型证明。
