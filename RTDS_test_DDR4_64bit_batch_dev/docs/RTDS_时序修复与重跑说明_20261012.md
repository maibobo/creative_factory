## MIG为什么存在违例、如何处理

MIG也是需要满足布局布线后时序的同步逻辑。其内部UI时钟为300MHz，周期3.333ns。当前最差路径为事务队列寄存器到周期读地址寄存器的使能端；数据延迟3.172ns，其中逻辑1.026ns、布线2.146ns（67.654%）。加上负时钟偏斜、时钟不确定性及触发器建立要求后，裕量为-0.168ns。

新增恢复逻辑可能改变整机布局和布线资源分配，影响原先接近极限的MIG路径；报告只能证明此次关键路径布线占比高，不能单独证明新增RTL是唯一原因。当前采用更强布局、布线和布线后物理优化缩短真实路径，保留MIG原300MHz约束及厂商逻辑。若下一轮仍存在违例，应依据新报告继续做针对关键单元的局部物理优化；不能将MIG同步路径设为false path，或放宽周期来关闭问题。
