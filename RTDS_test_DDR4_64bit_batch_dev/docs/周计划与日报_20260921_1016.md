## 第四周（2026/09/21 ~ 2026/09/25）

### 周计划标题
CPU-PCIe-Aurora交互模块新增需求设计工作——完成V2.01主机规格与寄存器表单定版、时序违例修复闭环、软件联调设计输入准备

### 周一（2026/09/21）：剩余时序违例修复与新增需求设计梳理
工作计划：定位上轮实现唯一 setup 违例（`ui_reset_pipe_reg[1]_replica` → `ready_sync_reg[0]/D`，MIG 300MHz → 控制域 250MHz，WNS -2.768ns）；分析根因为 DDR4_PIN.xdc 使用 `if` 包裹 `set_false_path` 不被 read_xdc 支持（CRITICAL WARNING 20-1307），改为直接 false_path + 完整层级正则只选首级同步器 D 端；配合 GUI 重新实现，验证最终时序 WNS +0.011ns / WHS +0.004ns 全部约束满足，报告同步 reports/timing_fix_gui_20260921；同步梳理《新增需求_主机逻辑与验证说明》遗留项，确认十组 duty/Vin 配置表与 100ms 八块方案已定版。

### 周二（2026/09/22）：主机上下行规格与寄存器表单整理
工作计划：基于《PCIe交互协议_V2.01.md》与《V2.01_整体设计与验证架构》输出《主机规格与寄存器总结》：三条数据通路（下行 16Byte 帧→10G、1G 6Byte 参数通道、上行低 32bit→100ms×8块DDR）、DDR 4MiB 地址映射（下行 32KiB 窗口 0x8000~0xFFFF、上行 2MiB 八块 0x100000~0x2FFFFF）、14 个寄存器偏移（0x00~0x38）、下行/上行门铃操作流程及软件可靠性边界；寄存器表与 INFO_EXCH.v RTL 读复用逻辑逐项核对一致（0x14/0x20 门铃自动清零、0x24 复位默认 32KiB），确认 0x38 统计单位为 32bit 有效字。

### 周三（2026/09/23）：软件联调设计输入——寄存器手册素材
工作计划：整理寄存器手册格式素材：各寄存器位域定义、访问权限（只读/写 1 清零/读清）、复位默认值、忙期间写入忽略规则；整理软件操作时序：下行"等 0x20==0 → 写 0x24/0x28 → H2C → 写 0x20=1 → 等清零"、上行"读清 0x10 → 读 0x18/0x1C/0x34 → C2H → 写 0x14=1"；明确单一消费者、禁止双线程分别读头和确认、DMA/MMIO 必须使用驱动完成与顺序保证等约束条款。

### 周四（2026/09/24）：联板观察顺序与异常场景用例设计
工作计划：制定联板观察顺序：DDR 校准完成 → PCIe 链路/版本 → 下行配置提交 → 10G 原帧 → 1G 已配置编号/两拍握手 → 100ms 块发布 → C2H 实际完成 → ACK 后队头推进；设计异常场景用例：积压试验通过延迟软件 ACK 并检查 0x30/0x38、八块满不覆盖验证、1G 反压跳过机会不积压、写响应错误后从未提交位置覆盖继续、空块不发布不产生中断；明确不以未完成 DMA 提前 ACK 制造数据损坏。

### 周五（2026/09/25）：新增需求设计评审收尾
工作计划：组织 V2.01 新增需求设计评审：确认与 V2.00 差异清单（128Byte→16Byte 帧、按帧计数→32bit 字丢失计数、2µs 跨域→63 拍 2.016µs、上行去高 32bit 紧凑写入）；确认验证基线（模块级前仿 2026-09-20 全部 PASS、顶层综合 0 错误 0 警告、静态时序满足但 WNS 余量仅 +0.011ns 列为联调监控项）；汇总遗留问题（完整 Root Port 闭环停在 RP Polling.Active、1 个 input delay / 3 个 output delay 板级约束缺失、尚无上板证据）；输出下周软件联调环境搭建计划。

### 周总结
**详细版**：
1. 完成剩余时序违例修复闭环：定位 XDC `if` 语句不被 read_xdc 支持的根因，改为直接 false_path 后重新实现，WNS 由 -2.768ns 修复至 +0.011ns，全部用户约束满足，报告归档 reports/timing_fix_gui_20260921。
2. 完成《主机规格与寄存器总结》定版：覆盖三条数据通路、DDR 4MiB 映射、16Byte 下行/63 拍 1G/低 32bit 上行完整规格、14 个寄存器表（与 RTL 核对一致）、软件操作流程与可靠性边界，作为软件联调的统一基线。
3. 完成软件联调设计输入准备：寄存器手册素材、MMIO/DMA 操作时序、联板观察顺序与异常场景用例（积压/反压/掉线/写错误）设计，明确遗留问题清单与下周计划。

**简要版**：完成 V2.01 新增需求设计定版——时序违例修复闭环（WNS +0.011ns）、主机规格与寄存器总结产出、软件联调设计输入就绪。

**本周产出物**：《主机规格与寄存器总结.md》《V2.01_剩余时序违例修复_20260921.md》、reports/timing_fix_gui_20260921 时序报告、联板观察顺序与异常用例清单、V2.00/V2.01 差异清单。

## 第五周（2026/09/28 ~ 2026/10/10，有效工作日 6 天：09/28~09/30、10/08~10/10）

> 10/01 ~ 10/07 国庆节假期

### 周计划标题
CPU-PCIe FPGA交互模块软件联调环境搭建——完成驱动与BAR映射、寄存器访问与DMA通道配置、中断链路与调试探针部署，达到环境就绪判据

### 周一（2026/09/28）：驱动环境与BAR映射搭建
工作计划：搭建 CPU 侧驱动环境：加载 XDMA 驱动、确认设备枚举与 BAR 分配，梳理 AXI-Lite BAR（寄存器块）与用户 BAR（DDR 共享空间）映射关系，确认 XDMA/CONV_DMA 低 4MiB 映射一致、无旧 64KiB 索引残留；建立 MMIO 读写封装函数，规划驱动侧完成与顺序保证机制（DMA 完成回调、内存屏障）。

### 周二（2026/09/29）：寄存器访问通路验证
工作计划：逐个验证 14 个寄存器访问：读 0x00 期望 0x00002001、0x04 期望 0x20260914、0x08 期望 0x00040000；验证 0x10 读清行为、0x14 写 1 确认脉冲、0x20 门铃自动清零、忙期间 0x24/0x28 写入忽略；验证空队列时 0x18/0x1C/0x30 读 0；记录每个寄存器的实测值与文档值比对表。

### 周三（2026/09/30）：H2C/C2H DMA 通道配置
工作计划：配置并验证 H2C/C2H DMA 通道：H2C 向下行窗口 0x8000~0xFFFF 写入测试数据并回读校验；C2H 从上行窗口地址搬运并核对数据完整性；验证 16Byte 对齐与 4Byte 长度粒度约束在驱动侧的检查逻辑；确认 DMA 完成信号真实返回后才允许后续门铃操作。

### 周四（10/08，国庆后首个工作日）：中断接收链路准备
工作计划：搭建中断接收链路：配置 MSI/IRQ 使能，验证 xdma_irq_monitor 观察路径（请求、MSI 使能及 ACK），不能只看用户 IRQ 信号；实现上行块发布→中断→软件读队头→ACK→重新通知的完整事件处理框架；编写中断时延与到达率统计工具，为联调阶段性能数据采集做准备。

### 周五（10/09）：调试探针与调试脚本部署
工作计划：部署调试手段：按原生时钟分别布置 ILA 探针观察 PCIe 域、DDR 域与 Aurora 域关键信号（不为测试额外建立业务数据路径）；整理调试脚本：scripts/resume_rootport_v201.tcl（Root Port 闭环复跑入口）、scripts/refresh_batch_bd.tcl（BD 重新生成，生成后强制同步仿真导出）；复跑 Root Port 闭环仿真，确认 RP Polling.Active 阻塞点是否解除。

### 周六（10/10）：联调环境就绪验收
工作计划：执行环境就绪判据验收：上电后 PCIe 链路训练成功、枚举到设备、读 0x00 返回 0x00002001；H2C/C2H 各完成一次最小数据量回环校验；中断收发一次完整；ILA 触发与脚本入口可用；输出《软件联调环境搭建验收清单》与遗留问题清单，确认是否具备进入基本通路联调条件。

### 周总结
**详细版**：
1. 完成驱动与寄存器通路搭建：XDMA 驱动加载、BAR 映射确认（AXI-Lite 寄存器块 + 用户 DDR 空间低 4MiB），14 个寄存器逐项实测与文档比对，0x00 读出 0x00002001 判据通过。
2. 完成 DMA 通道与中断链路配置：H2C/C2H 通道数据回环校验通过，16Byte 对齐与 4Byte 粒度驱动侧检查就位；MSI/IRQ 收发与"发布→读头→ACK→再通知"事件框架可用，中断时延/吞吐统计工具就绪。
3. 完成调试手段部署与环境验收：ILA 探针按域布置、Root Port 闭环复跑入口与 BD 再生成脚本整理；输出《软件联调环境搭建验收清单》，具备进入基本通路联调条件（遗留项单独列出）。

**简要版**：完成软件联调环境搭建——驱动/BAR/寄存器/DMA/中断通路与调试探针全部就绪，环境就绪判据（读 0x00 = 0x00002001 + DMA 回环 + 中断收发）通过。

**本周产出物**：寄存器实测比对表、DMA 通道配置记录、中断事件处理框架与统计工具、ILA 探针部署清单、《软件联调环境搭建验收清单》。

## 第六周（2026/10/12 ~ 2026/10/16）

### 周计划标题
CPU-PCIe FPGA交互模块软硬件基本通路联调——完成上板环境准备、PCIe链路枚举与寄存器联调、DMA数据通路与中断联合调试及联调报告输出

### 周一（2026/10/12）：上板环境准备与底层链路打通
工作计划：完成上板环境准备：加载 bitstream，按联板观察顺序推进最前两级——DDR4 校准完成（MIG init_done，确认 2400 配置静态时序结论在实板成立）、PCIe 链路训练与设备枚举成功；确认 WNS +0.011ns 余量时钟域（xdma_0_axi_aclk）在实板温度/电压下无异常；记录上电到枚举的耗时与首次链路训练状态。

### 周二（2026/10/13）：寄存器联调与版本/状态核对
工作计划：板卡实测寄存器联调：核对 0x00/0x04/0x08 版本与容量寄存器；实测 0x0C 温度读数合理性；验证 0x10 读清、0x14 确认脉冲、0x20 门铃自动清零的板上时序；用 ILA 抓取门铃写入到硬件响应的波形，确认忙期间重复提交不重复启动、非法范围不访问 DDR。

### 周三（2026/10/14）：下行数据通路联调（CPU → 10G → 1G）
工作计划：联调下行通路：CPU 提交整批 16Byte 帧（先小批量再 32KiB 满窗），ILA 观察每帧一次 DDR 读突发经异步 FIFO（阈值 504）送 10G LocalLink，逐拍比对帧内容与原始数据；验证首次合法 Byte1（编号 1~10）锁存 duty/Vin，48bit 握手 CDC 到 1G 域，63 拍周期两拍发送（第二拍高 16bit、REM=1）；验证非法编号不配置、重复合法帧不改锁存值、忙时跳过机会不积压。

### 周四（2026/10/15）：上行数据通路与中断联合调试（10G → DDR → CPU）
工作计划：联调上行通路：10G 注入已知测试流，确认每有效 64bit 拍低 32bit 紧凑写入、两个低 32bit 拼一个 DDR 写拍、奇数尾字 WSTRB=0x0F；验证 100ms 边界封存与在途写响应完成后再发布、空块不发布；CPU 收中断→读 0x18/0x1C/0x34/0x30→C2H 搬运→写 0x14 确认→队头推进→剩余块重新通知；核对批次序号 0x34 递增与首块为 0。

### 周五（2026/10/16）：异常场景联调与总结报告输出
工作计划：执行异常场景：延迟软件 ACK 制造积压，检查 0x30 递增至 8 后不覆盖旧块、0x38 字丢失计数变化后排空恢复；1G 反压与链路掉线恢复（不补发历史机会、参数保持）；下行忙期间提交与越界请求拒绝。汇总联调结果——链路枚举、寄存器访问、DMA 传输、中断、异常场景五类测试项通过状态与性能数据；整理 ILA 波形截图、误码率统计、中断时延、吞吐率实测数据；输出《CPU-PCIe FPGA交互模块软件联调报告》，含仿真与实测结果对比、问题清单（现象-根因-归属-修复建议）、遗留问题与后续计划。

### 周总结
**详细版**：
1. 完成底层链路与寄存器联调：DDR4 校准通过、PCIe 链路枚举成功，版本/状态/门铃寄存器板卡实测与文档一致，ILA 波形确认门铃自动清零、忙时重复提交保护、非法范围拒绝行为正确。
2. 完成下行与上行数据通路联调：下行 16Byte 帧经 10G 逐拍比对通过、1G 十组参数配置锁存与 63 拍两拍发送验证通过；上行低 32bit 紧凑写入、100ms 八块封存发布、C2H 搬运与 ACK 队头推进闭环打通，批次序号与待取块数行为正确。
3. 完成异常场景联调与报告输出：积压（延迟 ACK）、八块满不覆盖、1G 反压/掉线恢复、0x38 字丢失计数等异常行为验证；输出《CPU-PCIe FPGA交互模块软件联调报告》，含五类测试项通过状态、仿真与实测对比、问题清单（现象-根因-归属-修复建议）及遗留问题与后续计划。

**简要版**：完成软硬件基本通路联调——PCIe 枚举/寄存器/下行/上行/中断全链路打通并通过异常场景验证，输出软件联调报告与问题清单。

**本周产出物**：《CPU-PCIe FPGA交互模块软件联调报告》、ILA 波形截图与实测数据（中断时延、吞吐率、误码统计）、问题清单（现象-根因-归属-修复建议）、遗留问题与后续计划。
